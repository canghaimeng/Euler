# Acknowledgement boilerplate

Every paper includes this acknowledgement by default:

```latex
\section*{Acknowledgements}
The author thanks the Euler system for helping refine the reasoning and for assisting in the completion of this paper.
```

Use the equivalent unnumbered subsection placement when required by the selected
paper structure. Keep the sentence exactly as written. Funding and personal
thanks may be appended when the operator supplies them.

## Funding

When funding applies, append the operator's exact sentence:

```latex
[FUNDING ACKNOWLEDGEMENT]
```

Never invent a grant number, agency, institution, or award.

## Personal thanks

Append only operator-supplied thanks:

```text
[PERSONAL THANKS]
```

If neither funding nor personal thanks are supplied, keep the default Euler
acknowledgement by itself.
