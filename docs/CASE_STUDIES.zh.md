# 在标准 Euler 工作台中阅读历史项目

历史项目使用与原生 Euler 项目相同的概览、证明阅读、研究现场、关系图和诊断视图，通过已有项目目录选择，沿用标准工作台布局。

将服务端 `EULER_CASE_STUDIES_MANIFEST` 指向冻结的来源清单，并在相应项目的工作台配置中设置 `case_study_id`。`historical_projection` 适配器将有来源支持的模块、路线、障碍和证据映射到已有读取模型，与原控制器视图并列提供只读展示。

证明组件使用独立的 DOCUMENTED／Recorded 状态。只有所选来源阶段确实支持时，才展示路线的拒绝、搁置或完成结果。原控制器状态与形式化验收分别保留；冻结来源记录保留原始证据类型和验证日期。

整理后的概览模块使首屏简洁，标准关系图展示完整、受来源支持的依赖结构和历史上下文。每个派生节点都可在证明阅读器中打开，查看绑定来源的说明和原始片段。研究现场同时包含选定的历史 O/R/B/E 里程碑和原有共享记录。

来源文件必须位于配置包内，不能使用符号链接。来源变化或不可用时，派生结构会撤回。来源哈希用于确认记录完整性；验证记录决定展示的数学证据等级。访问控制和项目隔离继续适用，私有研究包保留为部署数据。

旧 `/static/cases.html` 书签会重定向到标准工作台。

## 已有验收证据

经审阅的 `verification_binding` 可将证明模块对应到历史已接受 Facts 或归档的内核审计。Fact 绑定要求内容哈希一致、入库仍有效且原始验证成功；内核绑定需指明检查过的声明和完整源码审计。展示的检查保留原始来源；绑定失效时标为 stale。只有来源、没有验证绑定的节点继续保持未验证。

展示保留真实 Fact 前驱边与原始验证结果。主结论在研究读取模型中具有明确的闭合路线；若存在最终已入库 Fact，也以它作为事实图主线锚点。所有来源均可在常规阅读器和证据详情中查看。
