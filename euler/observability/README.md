# Euler observability

Personal multi-project workbench with proof architecture, live exploration,
source-grounded reading, dependency maps and operational diagnostics.

```bash
euler-dashboard --project /absolute/path/to/project --config /absolute/path/to/dashboard.json
```

English by default, with a Chinese UI toggle. Original mathematical text is preserved.
Configured personal projects support team questions and milestone recovery without
a separate control password. Static dependencies ship in the wheel. No frontend build service is required.
See [deployment and catalog configuration](../../docs/DASHBOARD.md),
[reader guide](../../docs/DASHBOARD-GUIDE.md) and
[contributor instructions](../../CONTRIBUTING.md).
